管理页 预览主页

TXT → PNG

纯色背景 + 纯色文字，尺寸对齐橱窗格子（1x1 / 1x2 / 1x4 / 2x2 / 2x4）。 字体用本机装了的那些，导出的图片就是现在预览里的样子。

PNG → SVG

描摹模式会把同色区域变成真正的矢量路径——扁平色块的图（文字图、logo、图标） 效果最好；照片会变成海报风。只想把像素原样装进 SVG 就用「直接嵌入」。
